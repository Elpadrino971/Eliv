# Fiches App Store et Google Play — 12 langues

Textes prêts à copier-coller pour la version 1.2.0.

**Où coller :**
- **App Store Connect** : page de la version → menu de langue en haut à droite → *Ajouter une langue*.
  - Sur la page de la version : *Texte promotionnel*, *Description*, *Mots-clés*, *Nouveautés*.
  - Dans *Informations sur l'app* : *Sous-titre*.
- **Google Play Console** : *Présence sur le Store → Fiche principale → Gérer les traductions*.
  - *Description courte* (80 caractères).
  - *Description complète*.
  - Les *Nouveautés* se mettent dans la release.

**Limites respectées :**
- sous-titre ≤ 30 caractères ;
- description courte Play ≤ 80 ;
- texte promotionnel ≤ 170 ;
- mots-clés ≤ 100 octets (Apple compte en octets : les langues à caractères non latins ont donc moins de mots), séparés par des virgules sans espace, sans répéter le nom de l'app.

**Avant de publier, fais relire les langues que tu ne lis pas** (chinois, coréen, japonais, arabe, hindi, russe) par un locuteur natif si possible.

Le texte promotionnel se modifie à tout moment sans nouvelle vérification Apple. Pour le concert de Wilson en français :

> DJ Wilson en live ce samedi : prends ta place et vis le concert depuis ton téléphone, où que tu sois.
