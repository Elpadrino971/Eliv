Dossier des animations de cadeaux / pourboires (site web).

➜ Dépose ici un fichier par cadeau. Formats supportés : .json (Lottie), .webm, .mp4, .gif
➜ Nomme les fichiers d'après le cadeau (en minuscules), par ex. :
     rose.webm
     coeur.webm
     etoile.json
     diamant.json
     feu.webm
     couronne.json
     fusee.webm
     chateau.json

Ensuite, dis-moi le format + le mapping (cadeau → fichier) et je branche tout
dans flyGift() (site) et gift_animation_manager.dart (app Flutter).

Pour l'app mobile Flutter, les animations vont dans : assets/animations/
(et doivent être déclarées dans pubspec.yaml, section "assets:").
